## ✅ ВЫПОЛНЕННЫЕ ЗАДАНИЯ

### Linux (1-5):
1. **Использование команды cat** - созданы файлы Pets.txt и PackAnimals.txt
2. **Работа с директориями** - создана директория AnimalFiles
3. **Установка MySQL** - скрипт mysql_installation.sh
4. **Управление deb-пакетами** - команды dpkg
5. **История команд** - сохранение в terminal_history.txt

### ООП (6-10):
6. **Диаграмма классов** - PlantUML диаграмма в docs/class_diagram.puml
7. **База данных MySQL** - полный SQL скрипт database/human_friends.sql
8. **Иерархия классов Java** - полная реализация всех классов
9. **Программа-реестр** - консольное приложение с меню
10. **Счетчик животных** - статический счетчик в классе Animal

## 🚀 ЗАПУСК ПРОГРАММЫ

### Windows:
```cmd
build.bat compile  # Компиляция
build.bat run      # Запуск
build.bat help     # Справка
```

### Linux/Mac:
```bash
make compile  # Компиляция
make run      # Запуск
make help     # Справка
```

### Прямой запуск:
```bash
javac src/main/java/*.java
java -cp src/main/java Main
```
