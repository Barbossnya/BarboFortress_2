# Система учета питомника - BarboFortress_2

## Информация о проекте

Система учета для питомника, в котором живут домашние и вьючные животные.

## Структура проекта

### Java классы (ООП)
- `Animal.java` - базовый абстрактный класс для всех животных
- `Pets.java` - абстрактный класс для домашних животных
- `PackAnimals.java` - абстрактный класс для вьючных животных
- `Dog.java`, `Cat.java`, `Hamster.java` - классы домашних животных
- `Horse.java`, `Camel.java`, `Donkey.java` - классы вьючных животных
- `AnimalRegistry.java` - основной класс реестра животных
- `Main.java` - главный класс для запуска программы

### Linux команды
- `linux_commands.sh` - скрипт для создания файлов с животными
- `mysql_installation.sh` - скрипт для установки MySQL

### База данных
- `database/human_friends.sql` - SQL скрипт для создания базы данных

## Функциональность программы

### 9. Программа-реестр домашних животных

#### 9.1. Добавление нового животного
- Реализована функциональность для добавления новых животных в реестр
- Животное определяется в правильный класс (собака, кошка, хомяк, лошадь, верблюд, осел)

#### 9.2. Список команд животного
- Выводится список команд, которые может выполнять добавленное животное

#### 9.3. Обучение новым командам
- Добавлена возможность обучать животных новым командам

#### 9.4. Список животных по дате рождения
- Выводится список животных, отсортированный по дате рождения

#### 9.5. Навигация по меню
- Реализован консольный пользовательский интерфейс с меню

### 10. Счетчик животных
- Создан механизм, который позволяет вывести общее количество созданных животных
- При создании каждого нового животного счетчик увеличивается на "1"

## Запуск программы

### Требования
- Java 8 или выше
- MySQL (для работы с базой данных)

### Компиляция и запуск
```bash
# Компиляция
javac src/main/java/*.java

# Запуск
java -cp src/main/java Main
```

### Работа с базой данных
```bash
# Подключение к MySQL
mysql -u root -p

# Выполнение SQL скрипта
source database/human_friends.sql
```

### Linux команды
```bash
# Выполнение скрипта создания файлов
chmod +x linux_commands.sh
./linux_commands.sh

# Установка MySQL
chmod +x mysql_installation.sh
./mysql_installation.sh
```

## Примеры использования

1. **Добавление животного:**
   - Выберите тип животного (1-6)
   - Введите имя
   - Введите дату рождения (формат: yyyy-MM-dd)

2. **Просмотр команд:**
   - Выберите животное из списка
   - Просмотрите список доступных команд

3. **Обучение новой команде:**
   - Выберите животное
   - Введите новую команду

4. **Просмотр по дате рождения:**
   - Автоматическая сортировка всех животных по дате рождения

5. **Счетчик животных:**
   - Отображение общего количества животных
   - Разделение на домашних и вьючных животных
