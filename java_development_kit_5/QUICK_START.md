# Быстрый запуск телефонного справочника

## Вариант 1: Mock версия (БЕЗ базы данных) 🚀

**Для быстрого тестирования GUI без настройки PostgreSQL:**

1. Откройте файл `src/main/java/gb/jdk_5/App.java`
2. Закомментируйте строку с `PhonebookGUI.class`
3. Раскомментируйте строку с `PhonebookGUIMock.class`:

```java
// 1. Версия с базой данных PostgreSQL (требует настройки БД)
// Application.launch(PhonebookGUI.class, args);

// 2. Mock версия без базы данных (для тестирования)
Application.launch(PhonebookGUIMock.class, args);
```

4. Запустите приложение:
```bash
mvn clean javafx:run
```

**Преимущества Mock версии:**
- ✅ Не требует настройки PostgreSQL
- ✅ Работает сразу после компиляции
- ✅ Содержит тестовые данные
- ✅ Демонстрирует многопоточность
- ✅ Показывает все функции GUI

## Вариант 2: Полная версия (С базой данных) 🗄️

**Для работы с реальной базой данных PostgreSQL:**

### Настройка PostgreSQL:

1. **Установите PostgreSQL:**
   - Windows: https://www.postgresql.org/download/windows/
   - macOS: `brew install postgresql`
   - Linux: `sudo apt-get install postgresql`

2. **Создайте базу данных:**
```sql
CREATE DATABASE phonebook_database;
```

3. **Выполните SQL скрипт:**
```bash
psql -d phonebook_database -f src/main/java/gb/jdk_5/Database/phonebook_database.sql
```

4. **Обновите параметры подключения** в `src/main/java/gb/jdk_5/Controller/GuiPersonController.java`:
```java
String user = "postgres"; // Ваш пользователь PostgreSQL
String password = "password"; // Ваш пароль
```

5. **Запустите приложение:**
```bash
mvn clean javafx:run
```

## Функциональность приложения

### ✅ Добавление нового человека
- Заполните форму: Фамилия, Имя, Отчество, Дата рождения, Телефон, Пол
- Нажмите "Добавить"
- Операция выполняется в фоновом потоке

### ✅ Поиск по фамилии
- Введите часть фамилии в поле поиска
- Нажмите "Поиск"
- Результаты отображаются в списке

### ✅ Просмотр всех записей
- Нажмите "Обновить список"
- Все записи загружаются из источника данных

### ✅ Удаление записи
- Выберите запись в списке
- Нажмите "Удалить выбранного"
- Запись удаляется из источника данных

## Многопоточность в действии

### 🔄 Асинхронные операции
- Все операции с данными выполняются в фоновых потоках
- UI остается отзывчивым во время операций
- Индикатор загрузки показывает прогресс

### 🛡️ Безопасность потоков
- `Platform.runLater()` для обновления UI из фоновых потоков
- Пул потоков для управления ресурсами
- Корректная обработка ошибок
