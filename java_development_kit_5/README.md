# Телефонный справочник с GUI и многопоточностью

## 📋 Описание проекта

Графический интерфейс для телефонного справочника, реализованный с использованием JavaFX и многопоточности. Проект демонстрирует современные подходы к разработке GUI приложений с асинхронными операциями.

## 🏗️ Архитектура

### Многопоточность
- **Главный поток**: UI и обработка событий JavaFX
- **Пул потоков**: Операции с данными (ExecutorService)
- **Синхронизация**: `Platform.runLater()` для безопасного обновления UI

### Компоненты
- `PhonebookGUI` - основное окно приложения
- `GuiPersonController` - контроллер с многопоточностью
- `GuiPersonView` - интерфейс для обновления UI
- `Person` - модель данных

## 🚀 Быстрый запуск

### Вариант 1: Mock версия (БЕЗ базы данных) 🚀

**Для быстрого тестирования GUI без настройки PostgreSQL:**

1. Откройте файл `src/main/java/gb/jdk_5/App.java`
2. Закомментируйте строку с `PhonebookGUI.class`
3. Раскомментируйте строку с `PhonebookGUIMock.class`:

```java
// 1. Версия с базой данных PostgreSQL (требует настройки БД)
// Application.launch(PhonebookGUI.class, args);

// 2. Mock версия без базы данных (для тестирования)
Application.launch(PhonebookGUIMock.class, args);
```

4. Запустите приложение:
```bash
mvn clean javafx:run
```

### Вариант 2: PostgreSQL версия 🗄️

**Для работы с реальной базой данных:**

1. Установите PostgreSQL
2. Создайте базу данных `phonebook_database`
3. Выполните SQL скрипт из `src/main/java/gb/jdk_5/Database/phonebook_database.sql`
4. Обновите параметры подключения в `GuiPersonController.java`
5. Запустите приложение:
```bash
mvn clean javafx:run
```

## ✨ Функциональность

### ✅ Добавление нового человека
- Заполните форму: Фамилия, Имя, Отчество, Дата рождения, Телефон, Пол
- Нажмите "Добавить"
- Операция выполняется в фоновом потоке

### ✅ Поиск по фамилии
- Введите часть фамилии в поле поиска
- Нажмите "Поиск"
- Результаты отображаются в списке

### ✅ Просмотр всех записей
- Нажмите "Обновить список"
- Все записи загружаются из источника данных

### ✅ Удаление записи
- Выберите запись в списке
- Нажмите "Удалить выбранного"
- Запись удаляется из источника данных

## 🔧 Технические особенности

### Многопоточность в действии
- **Асинхронные операции** - все операции с данными выполняются в фоновых потоках
- **Отзывчивый UI** - интерфейс остается активным во время операций
- **Индикация загрузки** - пользователь видит прогресс выполнения
- **Безопасность потоков** - корректное обновление UI из фоновых потоков

### Используемые технологии
- **JavaFX** - современный GUI фреймворк
- **CompletableFuture** - асинхронное программирование
- **ExecutorService** - управление пулом потоков
- **PostgreSQL** - реляционная база данных
- **JDBC** - подключение к базе данных

## 🎯 Преимущества реализации

1. **Отзывчивый интерфейс** - UI не блокируется при операциях
2. **Безопасность потоков** - корректное обновление UI из фоновых потоков
3. **Масштабируемость** - пул потоков позволяет обрабатывать несколько запросов
4. **Обработка ошибок** - все ошибки отображаются пользователю
5. **Индикация загрузки** - пользователь видит, когда выполняются операции
6. **Гибкость** - поддержка Mock и PostgreSQL версий
7. **Современная архитектура** - использование JavaFX и асинхронного программирования

## 🛠️ Требования

- Java 8 или выше
- Maven 3.6.3 или выше
- PostgreSQL (для полной версии)
- JavaFX (включен в зависимости)
