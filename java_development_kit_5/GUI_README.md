# Телефонный справочник с GUI

## Описание
Графический интерфейс для телефонного справочника, реализованный с использованием JavaFX и многопоточности.

## Особенности реализации многопоточности

### 1. Пул потоков для работы с базой данных
- Используется `ExecutorService` с фиксированным пулом из 4 потоков
- Все операции с БД выполняются в фоновых потоках
- UI остается отзывчивым во время операций с базой данных

### 2. Безопасное обновление UI
- Используется `Platform.runLater()` для обновления UI из фоновых потоков
- Все обновления интерфейса происходят в главном потоке JavaFX

### 3. Асинхронные операции
- `CompletableFuture` для асинхронного выполнения операций
- Неблокирующие вызовы для добавления, поиска и удаления записей

## Запуск приложения

### Предварительные требования
1. Установленная Java 8 или выше
2. Maven
3. PostgreSQL с настроенной базой данных

### Настройка базы данных
1. Создайте базу данных `phonebook_database`
2. Выполните SQL скрипт из `src/main/java/gb/jdk_5/Database/phonebook_database.sql`
3. Обновите параметры подключения в `GuiPersonController.java`:
   - `user` - имя пользователя PostgreSQL
   - `password` - пароль пользователя PostgreSQL

### Компиляция и запуск

```bash
# Компиляция проекта
mvn clean compile

# Запуск GUI приложения
mvn javafx:run
```

Или через Maven плагин:
```bash
mvn clean javafx:run
```

## Функциональность

### Добавление нового человека
- Заполните все поля формы
- Нажмите "Добавить"
- Операция выполняется в фоновом потоке
- Форма очищается после успешного добавления

### Поиск по фамилии
- Введите часть фамилии в поле поиска
- Нажмите "Поиск"
- Результаты отображаются в списке

### Просмотр всех записей
- Нажмите "Обновить список"
- Все записи загружаются из базы данных

### Удаление записи
- Выберите запись в списке
- Нажмите "Удалить выбранного"
- Запись удаляется из базы данных

## Архитектура

### Многопоточность
- **Главный поток**: UI и обработка событий
- **Пул потоков**: Операции с базой данных
- **Синхронизация**: `Platform.runLater()` для обновления UI

### Компоненты
- `PhonebookGUI` - основное окно приложения (заменяет PersonMenu)
- `GuiPersonController` - контроллер с многопоточностью (заменяет PersonController)
- `GuiPersonView` - интерфейс для обновления UI (заменяет PersonView)
- `Person` - модель данных

### Структура проекта
```
src/main/java/gb/jdk_5/
├── App.java                    # Главный класс приложения
├── Controller/
│   └── GuiPersonController.java # Контроллер с многопоточностью
├── Model/
│   └── Person.java             # Модель данных
├── View/
│   ├── GuiPersonView.java      # Интерфейс для GUI
│   └── PhonebookGUI.java       # Основное окно приложения
└── Database/
    └── phonebook_database.sql  # SQL скрипт для БД
```

## Преимущества реализации

1. **Отзывчивый интерфейс** - UI не блокируется при операциях с БД
2. **Безопасность потоков** - корректное обновление UI из фоновых потоков
3. **Масштабируемость** - пул потоков позволяет обрабатывать несколько запросов
4. **Обработка ошибок** - все ошибки отображаются пользователю
5. **Индикация загрузки** - пользователь видит, когда выполняются операции
6. **Современная архитектура** - использование JavaFX и асинхронного программирования
