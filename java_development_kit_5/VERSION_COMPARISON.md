# Сравнение версий телефонного справочника

## 📁 Основная версия (корневая папка)
**Версия с поддержкой Mock и PostgreSQL**

### Особенности:
- ✅ Две версии в одном проекте
- ✅ Mock версия для быстрого тестирования
- ✅ PostgreSQL версия для продакшена
- ✅ Легкое переключение между версиями

### Запуск:
```bash
# Mock версия (без БД)
# Измените App.java:
// Application.launch(PhonebookGUI.class, args);
Application.launch(PhonebookGUIMock.class, args);

# PostgreSQL версия
# Измените App.java:
Application.launch(PhonebookGUI.class, args);
// Application.launch(PhonebookGUIMock.class, args);

# Запуск
mvn clean javafx:run
```

---

## 📁 database_version/
**Чистая версия только с PostgreSQL**

### Особенности:
- ✅ Только PostgreSQL версия
- ✅ Чистая архитектура без Mock
- ✅ Готова для продакшена
- ✅ Отдельный Maven проект

### Запуск:
```bash
cd database_version
mvn clean javafx:run
```

---

## 🎯 Рекомендации по выбору версии

### Для разработки и тестирования:
**Используйте основную версию с Mock**

Преимущества:
- Быстрый запуск без настройки БД
- Демонстрация многопоточности
- Тестовые данные включены
- Легкое переключение между режимами

### Для продакшена:
**Используйте database_version**

Преимущества:
- Чистая архитектура
- Только необходимые компоненты
- Оптимизирована для PostgreSQL
- Готова к развертыванию

## 🚀 Быстрый старт

### Для новичков:
1. Используйте основную версию
2. Запустите Mock режим
3. Изучите GUI и многопоточность
4. При необходимости переходите к PostgreSQL

### Для опытных разработчиков:
1. Используйте database_version
2. Настройте PostgreSQL
3. Работайте с реальными данными
4. Развертывайте в продакшене
