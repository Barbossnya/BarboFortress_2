# Инструкции по запуску приложения Core_5

## Описание проекта
Этот проект демонстрирует:
1. **Резервное копирование файлов** - создание резервных копий всех файлов в директории
2. **Сжатое хранение игрового поля** - сохранение поля 3x3 в 3 байта

## Требования
- Java 8 или выше
- Компилятор javac

## Команды для запуска

### 1. Компиляция
```bash
javac src/*.java
```

### 2. Запуск приложения
```bash
java -cp src Main
```

## Структура проекта
```
Core_5/
├── src/
│   ├── Main.java              # Главный класс с демонстрацией
│   ├── BackupManager.java     # Резервное копирование файлов
│   └── TicTacToeField.java   # Работа с игровым полем
├── backup/                    # Папка с резервными копиями
├── game_field.dat            # Сжатое игровое поле (3 байта)
└── README.md                 # Документация проекта
```

## Технические особенности

### Алгоритм сжатия
- Каждое значение (0-3) занимает 2 бита
- 9 значений × 2 бита = 18 бит = 3 байта
- Используется битовая упаковка для экономии места

### Кодировка значений
- 0 = пустое поле
- 1 = крестик
- 2 = нолик  
- 3 = резервное значение
