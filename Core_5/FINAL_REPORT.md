## 🔧 Технические особенности

### Алгоритм сжатия игрового поля
```java
// Упаковка 9 значений в 3 байта
for (int i = 0; i < 9; i++) {
    int value = field[i] & 0x03;        // 2 младших бита
    int byteIndex = i / 4;              // Номер байта
    int bitOffset = (i % 4) * 2;        // Смещение в битах
    compressed[byteIndex] |= (value << bitOffset);
}
```

### Кодировка значений
- 0 = пустое поле
- 1 = крестик
- 2 = нолик
- 3 = резервное значение

## 🚀 Способы запуска

### 1. Локальный запуск
```bash
# Компиляция
javac src/*.java

# Запуск
java -cp src Main
```

### 2. 🐳 Запуск в Docker
```bash
# Сборка и запуск через Docker Compose
docker-compose up --build

# Или через Docker напрямую
docker build -t core5-app .
docker run -it --rm core5-app
```
