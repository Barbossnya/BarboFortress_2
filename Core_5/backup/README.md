# Core_5: Тонкости работы

## Описание проекта

Проект демонстрирует две основные задачи:

### 1. Резервное копирование файлов
Функция создает резервную копию всех файлов в директории (без поддиректорий) во вновь созданную папку `./backup`.

**Особенности:**
- Копирует только файлы (не папки)
- Создает папку backup автоматически
- Показывает информацию о скопированных файлах
- Обрабатывает ошибки

### 2. Работа с игровым полем крестиков-ноликов
Реализовано сжатое хранение игрового поля 3x3 в файл размером всего 3 байта.

**Принцип работы:**
- Каждое значение поля занимает 2 бита (0-3)
- 9 значений × 2 бита = 18 бит = 3 байта
- 0 = пустое поле
- 1 = крестик
- 2 = нолик  
- 3 = резервное значение

## Демонстрация работы

При запуске программа:

1. **Создает тестовые файлы** для демонстрации резервного копирования
2. **Создает резервную копию** всех файлов в папку `./backup`
3. **Демонстрирует игровое поле** крестиков-ноликов
4. **Сохраняет поле** в сжатом формате (3 байта)
5. **Загружает поле** из файла и проверяет корректность восстановления

## Технические детали

### Сжатие данных
Игровое поле 3x3 с 4 возможными значениями (0-3) упаковывается в 3 байта:
- Каждое значение: 2 бита (0-3)
- 9 значений × 2 бита = 18 бит
- 18 бит = 3 байта

### Алгоритм упаковки
```java
// Упаковка
for (int i = 0; i < 9; i++) {
    int value = field[i] & 0x03;        // 2 младших бита
    int byteIndex = i / 4;              // Номер байта
    int bitOffset = (i % 4) * 2;        // Смещение в битах
    compressed[byteIndex] |= (value << bitOffset);
}

// Распаковка
for (int i = 0; i < 9; i++) {
    int byteIndex = i / 4;
    int bitOffset = (i % 4) * 2;
    int value = (compressed[byteIndex] >> bitOffset) & 0x03;
    field[i] = value;
}
```
