**Функциональность:**
- Автоматическое создание папки `./backup`
- Копирование только файлов (без поддиректорий)

## ✅ Задача 2: Сжатое хранение игрового поля

**Реализация:** Класс `TicTacToeField` для работы с игровым полем 3x3

**Алгоритм сжатия:**
- Каждое значение (0-3) занимает 2 бита
- 9 значений × 2 бита = 18 бит = 3 байта
- Используется битовая упаковка

**Кодировка значений:**
- 0 = пустое поле
- 1 = крестик
- 2 = нолик
- 3 = резервное значение

**Пример работы:**
```
Исходное игровое поле:
| X |   | O |
-------------
|   | X |   |
-------------
| O |   | X |

Поле сохранено в файл game_field.dat (3 байта)
Поле загружено из файла game_field.dat

Загруженное игровое поле:
| X |   | O |
-------------
|   | X |   |
-------------
| O |   | X |

Проверка восстановления данных:
Данные восстановлены корректно
```

## Технические особенности

### Алгоритм сжатия
```java
// Упаковка 9 значений в 3 байта
for (int i = 0; i < 9; i++) {
    int value = field[i] & 0x03;        // 2 младших бита
    int byteIndex = i / 4;              // Номер байта (0, 0, 0, 0, 1, 1, 1, 1, 2)
    int bitOffset = (i % 4) * 2;        // Смещение в битах (0, 2, 4, 6, 0, 2, 4, 6, 0)
    compressed[byteIndex] |= (value << bitOffset);
}
```
