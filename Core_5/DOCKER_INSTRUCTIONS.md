# Запуск проекта Core_5 в Docker

## 🐳 Запуск в Docker

### Предварительные требования
- Docker Desktop установлен и запущен
- Docker Compose установлен

### Команды для запуска

#### 1. Сборка и запуск через Docker Compose
```bash
# Собрать образ и запустить контейнер
docker-compose up --build

# Запустить в фоновом режиме
docker-compose up -d --build

# Остановить контейнер
docker-compose down
```

#### 2. Запуск через Docker напрямую
```bash
# Собрать образ
docker build -t core5-app .

# Запустить контейнер
docker run -it --rm core5-app

# Запустить с монтированием папок
docker run -it --rm -v $(pwd)/backup:/app/backup core5-app
```

## 🔧 Структура Docker проекта

```
Core_5/
├── Dockerfile              # Конфигурация Docker образа
├── docker-compose.yml      # Конфигурация Docker Compose
├── .dockerignore          # Исключения для Docker
├── DOCKER_INSTRUCTIONS.md # Эти инструкции
├── src/                   # Исходный код Java
├── backup/                # Папка для резервных копий
└── game_field.dat        # Сжатое игровое поле
```

## 🎯 Преимущества Docker версии

1. **Изоляция** - приложение работает в изолированной среде
2. **Портативность** - можно запустить на любой системе с Docker
3. **Воспроизводимость** - одинаковое поведение на всех машинах
4. **Масштабируемость** - легко развернуть несколько экземпляров

## 📊 Мониторинг контейнера

```bash
# Посмотреть запущенные контейнеры
docker ps

# Посмотреть логи контейнера
docker logs core5-java-app

# Войти в контейнер для отладки
docker exec -it core5-java-app /bin/bash
```
