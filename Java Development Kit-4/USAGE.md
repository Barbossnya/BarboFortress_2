# Инструкция по использованию многопоточного загрузчика файлов

## Быстрый старт

### Способ 1: Запуск через скрипт
```bash
run.bat
```

### Способ 2: Прямой запуск
```bash
java -cp target/classes com.downloader.Main
```

### Способ 3: Тестовая демонстрация
```bash
java -cp target/classes com.downloader.TestDownloader
```

## Как использовать

1. **Запустите приложение** одним из способов выше
2. **Введите URL файла** для загрузки (должен начинаться с http:// или https://)
3. **Укажите количество потоков** (от 1 до 10)
4. **Введите путь для сохранения** или нажмите Enter для автоматического определения имени файла
5. **Дождитесь завершения** загрузки

## Примеры использования

### Пример 1: Загрузка тестового файла
```
URL: https://httpbin.org/bytes/1024
Потоков: 2
Результат: Файл размером 1KB загружен в 2 потока
```

### Пример 2: Загрузка большого файла
```
URL: https://speed.hetzner.de/100MB.bin
Потоков: 4
Результат: Файл размером 100MB загружен в 4 потока
```

## Возможности приложения

### ✅ Основные функции
- Многопоточная загрузка файлов
- Настройка количества потоков (1-10)
- Отображение прогресса загрузки
- Автоматическое определение размера файла
- Поддержка HTTP Range запросов

### ✅ Обработка ошибок
- Проверка доступности файла
- Валидация URL
- Таймауты соединения
- Graceful shutdown потоков

### ✅ Адаптивность
- Автоматический переход на однопоточную загрузку при недоступности размера файла
- Настройка таймаутов соединения
- Обработка различных HTTP кодов ответа

## Технические детали

### Архитектура
- **SimpleDownloader**: Основной класс загрузчика
- **DownloadTask**: Задача для отдельного потока
- **Main**: Пользовательский интерфейс
- **TestDownloader**: Демонстрационный класс

### Принцип работы
1. **Проверка файла**: HEAD запрос для определения размера и доступности
2. **Разделение на части**: Файл делится на равные части для каждого потока
3. **Параллельная загрузка**: Каждый поток загружает свою часть с Range запросами
4. **Объединение**: Части объединяются в финальный файл
5. **Очистка**: Временные файлы удаляются

### Ограничения
- Сервер должен поддерживать HTTP Range запросы
- Некоторые серверы могут ограничивать количество одновременных соединений
- Эффективность зависит от пропускной способности интернет-соединения

## Устранение неполадок

### Проблема: "Не удалось определить размер файла"
**Решение**: Приложение автоматически переключится на однопоточную загрузку

### Проблема: "HTTP ошибка: 403"
**Решение**: Сервер может блокировать запросы. Попробуйте другой URL

### Проблема: "Connection timeout"
**Решение**: Проверьте интернет-соединение и попробуйте снова

### Проблема: "No line found"
**Решение**: Убедитесь, что вводите данные корректно в интерактивном режиме

## Оптимизация производительности

### Рекомендации по количеству потоков:
- **1-2 потока**: Для медленного интернет-соединения
- **3-4 потока**: Для среднего интернет-соединения
- **5-8 потоков**: Для быстрого интернет-соединения
- **9-10 потоков**: Для очень быстрого соединения

### Факторы, влияющие на скорость:
- Пропускная способность интернет-соединения
- Поддержка Range запросов сервером
- Ограничения сервера на количество соединений
- Размер файла (большие файлы выигрывают от многопоточности)
