# Многопоточный загрузчик файлов

Приложение для загрузки файлов из интернета с использованием нескольких потоков для повышения скорости загрузки.

## Возможности

- ✅ Многопоточная загрузка файлов
- ✅ Настройка количества потоков (1-10)
- ✅ Отображение прогресса загрузки
- ✅ Поддержка HTTP Range запросов
- ✅ Автоматическое определение размера файла
- ✅ Безопасное завершение потоков

## Требования

- Java 11 или выше
- Maven 3.6 или выше

## Сборка проекта

```bash
mvn clean package
```

## Запуск приложения

### Способ 1: Через Maven
```bash
mvn exec:java -Dexec.mainClass="com.downloader.Main"
```

### Способ 2: Через JAR файл
```bash
java -jar target/multi-thread-downloader-1.0.0.jar
```

## Использование

1. Запустите приложение
2. Введите URL файла для загрузки
3. Укажите количество потоков (1-10)
4. Введите путь для сохранения файла (или нажмите Enter для текущей папки)
5. Дождитесь завершения загрузки

## Архитектура

### Основные классы

- `MultiThreadDownloader` - основной класс для многопоточной загрузки
- `Main` - главный класс с пользовательским интерфейсом
- `DownloadTask` - задача для отдельного потока загрузки

### Принцип работы

1. **Определение размера файла**: Используется HEAD запрос для получения размера файла
2. **Разделение на части**: Файл делится на равные части для каждого потока
3. **Параллельная загрузка**: Каждый поток загружает свою часть файла
4. **Объединение частей**: После завершения всех потоков части объединяются в один файл
5. **Очистка**: Временные файлы удаляются

## Преимущества многопоточной загрузки

- **Повышенная скорость**: Использование нескольких соединений одновременно
- **Лучшая утилизация канала**: Максимальное использование доступной пропускной способности
- **Отказоустойчивость**: При ошибке в одном потоке остальные продолжают работу
- **Возможность возобновления**: Технология Range запросов позволяет возобновить загрузку

## Ограничения

- Сервер должен поддерживать HTTP Range запросы
- Некоторые серверы могут ограничивать количество одновременных соединений
- Эффективность зависит от пропускной способности интернет-соединения
