# Java Development Kit_2 - Программные интерфейсы

## Описание проекта

Этот проект демонстрирует реализацию обобщённых (generic) классов и методов в Java. Основная задача - создать простой обобщённый класс пары и набор обобщённых методов для работы с ним.

## Структура проекта

```
Java Development Kit_2/
├── src/
│   ├── Pair.java          # Обобщённый класс пары
│   ├── PairUtils.java     # Утилитарный класс с обобщёнными методами
│   └── Main.java          # Главный класс для демонстрации
├── bin/                   # Скомпилированные .class файлы
└── README.md             # Этот файл
```

## Классы

### Pair<T, U>
Обобщённый класс для хранения пары значений разных типов.

**Основные методы:**
- `getFirst()` - получить первый элемент
- `getSecond()` - получить второй элемент
- `setFirst(T first)` - установить первый элемент
- `setSecond(U second)` - установить второй элемент
- `of(T first, U second)` - статический метод для создания пары
- `toString()` - строковое представление пары
- `equals(Object obj)` - сравнение пар
- `hashCode()` - хеш-код пары

### PairUtils
Утилитарный класс с обобщёнными методами для работы с парами.

**Методы:**
- `sumPair(Pair<T, T>)` - сложение числовых пар
- `concatenatePair(Pair<String, String>)` - конкатенация строковых пар
- `swapPair(Pair<T, U>)` - обмен элементов пары
- `areEqual(Pair<T, T>)` - проверка равенства элементов
- `getMax(Pair<T, T>)` - поиск максимального элемента
- `getMin(Pair<T, T>)` - поиск минимального элемента
- `toStringWithSeparator(Pair<T, U>, String)` - преобразование в строку с разделителем

```bash
javac -d bin src/*.java
```

### Запуск
```bash
java -cp bin Main
```

## Примеры использования

### Создание пары
```java
Pair<Integer, String> pair = new Pair<>(42, "Ответ");
Pair<String, String> stringPair = Pair.of("Hello", "World");
```

### Работа с числовыми парами
```java
Pair<Integer, Integer> numbers = new Pair<>(10, 20);
double sum = PairUtils.sumPair(numbers); // 30.0
```

### Конкатенация строк
```java
Pair<String, String> strings = new Pair<>("Hello, ", "World!");
String result = PairUtils.concatenatePair(strings); // "Hello, World!"
```

### Обмен элементов
```java
Pair<String, Integer> mixed = new Pair<>("Возраст", 25);
Pair<Integer, String> swapped = PairUtils.swapPair(mixed); // (25, "Возраст")
```

## Особенности реализации

1. **Типобезопасность**: Все методы используют обобщённые типы для обеспечения типобезопасности на этапе компиляции.

2. **Ограничения типов**: Методы используют ограничения типов (например, `T extends Number`, `T extends Comparable<T>`) для обеспечения корректной работы с определёнными типами данных.

3. **Null-безопасность**: Методы корректно обрабатывают null значения.

4. **Переопределение методов**: Класс `Pair` переопределяет `toString()`, `equals()` и `hashCode()` для корректной работы с парами.

## Демонстрация возможностей

При запуске программы `Main` демонстрируются все возможности обобщённых классов и методов:
